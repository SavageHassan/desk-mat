# Shopify Desk Mat Store

Isolated development workspace for the Desk Mat Shopify storefront.

- `theme/` — working copy of the Shopify theme under development (CLI-connected)
- `backup-original-theme/` — untouched export of the store's original theme
- `docs/` — store audit, design direction, QA notes
- `assets-source/` — source imagery/assets before upload

All work for this store stays inside this directory.
