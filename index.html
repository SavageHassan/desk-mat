Shopify storefront

The DeskKart store runs on Shopify.

This repository holds the custom Shopify theme — Liquid templates, sections, assets and settings. Liquid is rendered by Shopify against live product and cart data, so the shop itself is served from the Shopify store, not from here.

Open the store preview View the theme source

Why this page, and not the shop?

Vercel serves static files and JavaScript apps. A Shopify theme is written in Liquid ({% section %}, {{ product.price }}), which only Shopify's servers can render — so a Vercel deployment of this repo has no storefront to build. Previously there was no index.html at the repository root either, which is why every path returned 404 NOT_FOUND.

The store is currently on a Shopify trial with the storefront password enabled, so the preview link above asks for the store password or a staff login. Publishing the theme and choosing a plan removes that.
